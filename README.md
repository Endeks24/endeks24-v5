# endeks24-v5

endeks24.com yeni tasarımının derlenmiş statik dosyaları (CSS ve JS). Dosyalar sürüm etiketleriyle (v5.x.y) jsDelivr üzerinden sunulur.

- Etiketli adresler değişmez: `https://cdn.jsdelivr.net/gh/Endeks24/endeks24-v5@v5.x.y/ortak.js`
- `anahtar.json` (main dalı): yayın yüzdesi ve geçerli sürüm etiketi.

Dosyalar elle değiştirilmez; her sürüm yeni bir etiketle yayımlanır.
